# Resume builder

The idea is to have a modular resume, where one file (let's call it "source file") acts as the master, and depending upon the job description, a few lines create a brand new resume.

Key objectives: 
- Modular, with minimal input
- Machine readable for ATS 
- Able to create a `.docx` and a `.pdf` file at the same time

Optional: 
- Be possible to make a cover letter out of the resume, using a template - at least to get started on.
